FormLens 0.9.3 — разбор движения по исходным кадрам

- Ниже видео появилась последовательность исходных кадров с измерениями и пояснениями.
- Для полного цикла руки показаны начало, максимальное сгибание и возврат. Проверка корпуса отмечается отдельно: измерена или пропущена.
- Если полного цикла нет, приложение показывает движение по шести временным участкам; ошибки техники не выдумываются.
- Неудачные измерения повторно проверяются по отдельному изображению и, где возможно, по области человека. Порог уверенности не снижен; замена человека и потеря уже доступных измерений запрещены.
- Ограничения объясняются на конкретных кадрах. Сводные проценты перенесены в раскрываемые подробности.
- Из кадра можно перейти к исходному видео и включить фрагмент со скоростью ×0,5. Кадры фаз включены в HTML-отчёт.
- Сохранённые разборы совместимы; для повторной проверки кадров нажмите «Повторить разбор».

Проверяется прежнее экспериментальное правило движения корпуса в горизонтальной тяге сидя. Эта версия не распознаёт упражнение и не оценивает все ошибки техники. Движение камеры, ракурс и перекрытия влияют на результат. Процент распознанных кадров не является точностью обнаружения ошибок.

Обновление через колокольчик. macOS Apple Silicon; без платного Apple Developer ID и нотарификации.
