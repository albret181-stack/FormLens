FormLens — экспериментальное локальное приложение для анализа видео горизонтальной тяги сидя.

В 0.7:
- Установочный DMG: перенесите FormLens в Applications.
- Колокольчик обновлений: проверка GitHub Releases при запуске, каждые 6 часов и вручную.
- Новая версия загружается через браузер; замена приложения из DMG пока выполняется вручную.
- Переносимые проекты, резервная предыдущая версия и три цветовые темы.

Только macOS Apple Silicon. Сборка имеет локальную ad-hoc подпись, без Apple Developer ID и нотарификации. Полная автоматическая установка обновлений не включена. Распознавание суставов настоящее, оценка техники экспериментальная и ещё не валидирована на размеченной выборке. Видео не отправляется на сервер.
