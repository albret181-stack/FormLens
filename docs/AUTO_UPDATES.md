# Обновления FormLens через GitHub

Приложение использует бесплатный Sparkle 2.10.1. ZIP и XML-лента подписываются Ed25519; постоянный публичный ключ находится в `config/update-public-key.txt` и в Info.plist установленного приложения. Приватный ключ не коммитится. Платные сертификаты Apple не требуются; эта сборка не нотарифицирована.

## Публикация с подписью вне GitHub

Этот способ не требует GitHub Secret: приватный ключ остаётся у издателя.

1. Собрать установщик с постоянным публичным ключом, пройти проверки и записать его Actions run в `config/update-request.json`.
2. `prepare-update.yml` извлекает уже проверенную .app из DMG, проверяет подпись приложения и публичный ключ, создаёт ZIP для обновления.
3. Скачать артефакт `FormLens-production-update` и подписать точный ZIP локально:

   ```bash
   node scripts/sign-prepared-update.mjs /path/FormLens-X.Y.Z-arm64.zip /private/path/key.txt PREPARE_RUN_ID
   ```

   Скрипт проверяет соответствие приватного ключа установленному публичному. В репозиторий выводятся только публичные подписи: `config/prepared-release.json` и `releases/FormLens-X.Y.Z-arm64-appcast.xml`.
4. Коммит этих публичных файлов запускает `publish-prepared-update.yml`. Workflow скачивает именно подписанный артефакт и проверяет SHA-256, подпись ZIP и подпись XML.
5. Создаётся предварительный выпуск. На отдельном Mac в CI проверяется реальная замена 0.9.0 → новая версия, отложенная установка, автоматический перезапуск и сохранение тестового проекта с Blob видео.
6. После этой проверки выпуск становится latest. Затем отдельно проверяются кнопки обновления установленной 0.9: поиск → скачивание → сохранение и перезапуск. При провале этой проверки выпуск снова становится предварительным и убирается из канала обновлений.

В тестах используются только искусственный проект и тестовые данные. Пользовательские видео и результаты не публикуются.

## Альтернативная публикация через GitHub Secret

Существующий `release.yml` позволяет собрать черновик выпуска по тегу `vX.Y.Z`, если владелец один раз добавил Actions Secret `FORMLENS_UPDATE_PRIVATE_KEY`. Публичный ключ берётся из репозитория. Не создавать новую пару ключей для уже установленного канала.

## Сценарий пользователя

Колокольчик (в меню «Ещё») → скачать обновление внутри FormLens → «Сохранить разбор и перезапустить». Для версии 0.8 и старше нужна однократная ручная установка версии с модулем обновлений.

Приложение принимает пакет только из своего репозитория и ленты конкретной версии. Sparkle проверяет подписи, выполняет замену и перезапуск. Перед установкой интерфейс сохраняет незавершённый разбор и блокирует установку при активном анализе или переносе. Подготовленное обновление может установиться также при обычном выходе.

Bundle ID `local.formlens.studio`, origin `http://127.0.0.1:4175` и профиль приложения остаются прежними. Проверки CI не имитируют карантин скачанного в браузере приложения и не заменяют проверку поведения Gatekeeper на пользовательском Mac.

## Артефакты выпуска

- `FormLens-X.Y.Z-arm64.dmg` — первая установка.
- `FormLens-X.Y.Z-arm64.zip` — встроенное обновление.
- `FormLens-X.Y.Z-arm64-appcast.xml` — подписанная лента версии.
- `appcast.xml` — та же лента для latest.
- `SHA256SUMS.txt` — контрольные суммы.

Первичные исходники: https://github.com/sparkle-project/Sparkle/tree/2.10.1 и https://sparkle-project.org/documentation/ . Формат подписанной XML-ленты соответствует `common_cli/Signing.swift` (`signAppcast`, без необязательного предупреждения).
