# FormLens Studio 0.7 — локальный разбор техники на тренажёре

Работающий экспериментальный прототип для macOS Apple Silicon (M1–M4 и новее). Один поддерживаемый сценарий: **горизонтальная тяга сидя на тросовом/блочном тренажёре, съёмка сбоку**. Приложение не определяет модель тренажёра автоматически. Пользователь выбирает соответствующее видео.

## Запуск готового приложения

1. Скачайте DMG из [GitHub Releases](https://github.com/albret181-stack/FormLens/releases/latest), откройте его и перенесите FormLens.app в Applications.
2. Откройте FormLens из «Программ».
3. Нажмите «Выбрать файл» или перетащите видео в область просмотра. Синтетическая схема интерфейса доступна только в разделе «О прототипе».

Модель и WebAssembly уже включены: интернет, Python, Node.js и учётная запись при этом не требуются. Сборка локальная, с ad-hoc подписью, без Apple Developer ID и нотарификации. Если политика вашего Mac запрещает её запуск, используйте исходники через `npm run web`. Приложение не изменяет настройки безопасности macOS.

Готовая сборка — arm64. Для Intel потребуется пересборка с `arch: 'x64'` в `scripts/package.mjs`. Intel и другие версии ОС в этой сессии не тестировались.

В нативном приложении появился колокольчик: проверка GitHub Releases при запуске, каждые 6 часов и по кнопке. При новой версии можно открыть загрузку DMG. **Установка пока ручная**, без автоматической замены приложения; для неё необходимы постоянная подпись Apple и отдельная проверка обновлений. В веб-предпросмотре сетевые проверки не запускаются.

32 программных теста проходят. Сборка DMG проверяется `hdiutil verify`, приложение — `codesign --verify`. Эти проверки не заменяют запуск на чистом Mac. Подготовлен GitHub Actions workflow для сборки последующих тегов в черновик Releases. Инструкция: [RELEASE.md](RELEASE.md).

## Версия 0.6 — перенос проектов и восстановление

- «Файл проекта ↓» сохраняет видео, точки, результаты, заметки и выбранные кадры в один `.formlens` (кадры восстанавливаются из исходного видео).
- «Мои разборы → Импортировать .formlens» проверяет размер, структуру, таймкоды и SHA-256 описания/каждого блока видео. Импорт всегда создаёт отдельную копию; чужие результаты помечены как не перепроверенные. Контрольная сумма выявляет повреждение, но не подтверждает автора или достоверность анализа.
- При повторном сохранении автоматически остаётся одна предыдущая версия. В библиотеке её можно восстановить; заменённая версия становится резервной. Это локальная защита, не замена отдельному файлу резервной копии.
- Перенос можно отменить. Видео обрабатывается блоками по 4 МБ без преобразования в base64; лимит — 500 МБ и 60 секунд.
- Формат — двоичный контейнер FLENS001: заголовок 48 байт, JSON-описание, исходные байты видео. Это не ZIP. Открывать следует через импорт FormLens, не двойным щелчком.

Проверено: 26 автоматических тестов и 10 изолированных браузерных проверок хранилища (миграция, откат, отказ записи, повторное открытие, удаление). Проверки хранилища запускаются по `/app/selftest-storage.html` через `npm run web`, используют отдельную временную базу и не входят в готовую сборку. Они не оценивают точность упражнений. Выбор места сохранения и импорт через системный диалог в нативной `.app` ещё требуют сквозной проверки; атомарная запись во внешний файл пока не реализована.

## Версия 0.4 — сохранённые разборы и отчёты

- **Сохранить на Mac**: явное сохранение копии исходного видео, названия, заметок, результатов, пары выбранных кадров и позиции воспроизведения. Доступно и до запуска анализа. Учебное демо в библиотеку не сохраняется.
- **Мои разборы**: список проектов, открытие без повторного анализа и удаление локальной копии с подтверждением. Оригинальный файл не удаляется.
- **Навигация по повторениям**: кнопки под видео с номерами и временем начала. Красная рамка указывает на повторение с наблюдением.
- **Отчёт с кадрами**: самостоятельный HTML-файл со встроенными изображениями, таймкодами, измерениями, статусом качества и заметками. Интернет не нужен. Для PDF откройте отчёт в браузере и выберите «Печать → Сохранить как PDF». Прямой экспорт PDF пока не реализован.
- **Защита от потери изменений**: предупреждение перед сменой файла, новым разбором и закрытием несохранённого проекта.

В версии 0.6 доступны три более спокойные цветовые темы. Проверка точности анализа упражнений остаётся следующим этапом. В этой итерации проверяется работа приложения, а не достоверность техники.

### Где находятся проекты

Используется IndexedDB в локальном профиле приложения. Сохранение происходит только по кнопке. Обычная загрузка файла сама по себе не добавляет его в библиотеку. Видео не отправляется по сети.

У macOS-приложения стабильный адрес `http://127.0.0.1:4175`, у режима `npm run web` — `http://127.0.0.1:4173`. Их хранилища раздельные. Не меняйте порт браузерного режима, если хотите видеть ранее сохранённые проекты. При занятом порте 4175 приложение показывает ошибку и не открывает посторонний сервис. Повторный запуск `.app` переключает на уже открытое окно.

Очистка данных приложения/браузера может удалить библиотеку. Это локальное хранилище, не облачная резервная копия. Храните оригиналы видео отдельно. При нехватке места сохранение завершается ошибкой; существующая версия проекта не заменяется частично. Экспорт HTML/JSON не является переносимым проектом для обратного импорта.

## Как пользоваться

- Подготовьте ролик от 1 до 60 секунд, до 500 МБ. Наиболее предсказуемый формат — MP4 с H.264. MOV/WebM работают, если их кодек декодируется Chromium.
- Снимайте одного человека сбоку неподвижной камерой. В кадре должны оставаться плечо, локоть, кисть, таз и колено на видимой стороне. Избегайте перекрытия тросами, стойками и другими людьми. Начало и конец движения рук должны попадать в ролик.
- Подтвердите условия съёмки и запустите анализ. Его можно отменить; частичные результаты удаляются.
- Выберите замечание: видео перейдёт к его таймкоду, а ниже появятся два кадра **из вашего файла** с суставами, траекторией кисти, выделением плеча и стрелкой.
- Кнопки времени под сравнением возвращают к соответствующим моментам. «＋ Кадр» позволяет вручную сохранить два произвольных кадра. Переключатель «Разметка» скрывает/показывает разметку.
- «Экспортировать разбор» выгружает JSON: таймкоды, повторения, измерения, координаты, параметры правила и тип источника. Само видео и изображения кадров в JSON не включаются.

**Демо отделено от анализа:** это программно нарисованная иллюстрация, с искусственными суставами и метриками. Она всегда помечена «ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ»; экспорт имеет `source: synthetic-demo`. Загруженный файл обрабатывается MediaPipe и имеет `source: user-video-mediapipe`. Реальное видео пользователя в исходном запросе отсутствовало.

## Что действительно анализируется

MediaPipe Pose Landmarker Lite оценивает 33 сустава. Инференс выполняется в Web Worker на CPU, локально. Видео анализируется с частотой **8 кадров/сек**. Это дискретные наблюдения, а не каждый кадр исходного видео.

1. Отбрасываются кадры без человека, с несколькими обнаруженными людьми, обрезанными/ненадёжными ключевыми суставами, слишком маленьким телом или явно неподходящей проекцией. Порог `visibility` — 0.75, это показатель модели, не вероятность правильности техники.
2. После первого пригодного кадра фиксируется видимая сторона тела. Углы считаются по пиксельным координатам с учётом пропорций видео.
3. Цикл повторения: угол локтя ≥130°, затем ≤90°, затем ≥130°. Длительность 1–10 секунд. Используется медианное сглаживание; пропуск распознавания разрывает цикл. Это экспериментальная схема выделения повторений, а не рекомендация по амплитуде упражнения. Частичные и не попавшие в пороги повторения не считаются.
4. Внутри полного цикла оценивается разница 80-го и 20-го процентилей наклона линии «таз—плечо». Если она больше **18°**, появляется «Заметное движение корпуса» — **возможная техническая ошибка**, с рекомендацией проверить стабильность корпуса и снизить вес. Процентили уменьшают влияние одиночных скачков. Два кадра соответствуют этим наблюдениям; ни один не объявляется эталоном.
5. При пригодности менее 80% кадров либо отсутствии полных циклов общий статус — **«Недостаточно данных»**. Ненадёжные интервалы от 0.375 секунды выделяются отдельно. Надёжно измеренное замечание на другом участке при этом сохраняется.
6. Если правило не сработало, статус — «Срабатываний правила нет», а не «Техника правильная».

Пороги находятся в `app/engine.mjs`. Они **не валидированы на размеченной выборке упражнений**. Эта версия не оценивает позвоночник/поясницу, нагрузку на суставы, движение лопаток, правильность хвата, настройку тренажёра или допустимую индивидуальную амплитуду. По одной 2D-проекции нельзя надёжно восстановить всё движение. Проверка бокового ракурса приблизительная; подтверждение неподвижной камеры остаётся ответственностью пользователя. Модель может пропустить второго человека или ошибочно поставить точки при перекрытии. Точность и полнота на реальных записях из зала пока неизвестны.

## Запуск исходников

Требования: macOS, Node.js 22 или новее, npm. Для первой установки зависимостей нужен интернет.

```sh
cd /путь/к/FormLens
npm ci
node scripts/setup.mjs
npm start
```

Либо двойной щелчок по `Запустить.command`. Если среда отключает install scripts npm, выполните `node node_modules/electron/install.js` перед `npm start`.

Вариант в локальном браузере:

```sh
npm run web
```

Откройте `http://127.0.0.1:4173/app/index.html`. Видео остаётся локальным и в этом варианте. Для остановки сервера нажмите Ctrl+C.

## Проверки и пересборка

```sh
npm test
npm run test:runtime
```

Второй режим выдаст адрес `/app/selftest.html`. В заголовке страницы ожидается `RESULT` с `ok:true`: загрузка модели, отсутствие позы на чёрном кадре, 33 точки на контрольном фото. Контрольное фото — тест модели, **не доказательство анализа упражнений на тренажёре**.

```sh
npm run package
codesign --force --deep --sign - ../build/FormLens-darwin-arm64/FormLens.app
codesign --verify --deep --strict ../build/FormLens-darwin-arm64/FormLens.app
```

Сборка появляется в `../build/FormLens-darwin-arm64/`. Для переносимости пакета используется локальный кэш загрузки Electron в `../../work/electron-cache`. Его можно удалить или изменить в скрипте сборки. Не требуются секреты и сертификаты.

## Что проверено 26 октября 2026

- 8 автоматических тестов правил: три цикла/одно замечание, перекрытие суставов, разрыв цикла на пропуске, одиночный выброс, статичная поза, отсутствие/несколько людей, геометрия углов и пустой ввод.
- Запуск настоящей MediaPipe-модели в worker локального браузера: чёрный кадр → ноль поз; контрольное фото → один человек и 33 точки.
- Полный путь загрузки MP4 без человека → 16 обработанных кадров, 0 повторений, «Недостаточно данных».
- Полный путь MP4 со статичным человеком → реальные суставы во всех 16 кадрах, 0 повторений, «Недостаточно данных»; ручное сравнение кадров из загруженного файла проверено.
- Учебный интерфейс: таймкод замечания, стрелка, суставы, траектория и сравнение двух моментов.
- macOS arm64 пакет собран. Запуск отдельного окна `.app` в этой среде не подтверждён: shell-запуск GUI завершился на регистрации macOS-приложения, а инструмент управления окнами сообщил об отсутствии разрешений. Проверка интерфейса и инференса проведена через локальный браузер. Не выдаём это за проверенный запуск `.app` у конечного пользователя.

## Устройство проекта

- `main.cjs` — Electron, окно с изолированным renderer; внешние сетевые запросы и разрешения камер/микрофона запрещены.
- `server.cjs` — сервер статических ресурсов только на `127.0.0.1`. В Electron используется стабильный порт 4175, в режиме браузера — 4173.
- `app/pose-worker.js` — настоящий MediaPipe, модель в `models/`.
- `app/engine.mjs` — проверяемые правила, не зависящие от интерфейса.
- `app/app.mjs` — видео, кадры, разметка, сравнение, экспорт.
- `app/storage.mjs` — атомарное сохранение и восстановление локальных проектов.
- `app/report.mjs` — самостоятельный HTML-отчёт с кадрами и экранированием пользовательского текста.
- `app/demo.mjs` — отдельные демонстрационные данные.
- `tests/engine.test.mjs` — автоматические проверки.

Загруженный файл читается через локальный Blob URL. До нажатия «Сохранить на Mac» он не копируется в библиотеку. После сохранения проект доступен в «Мои разборы» на том же устройстве и в том же профиле. Никакой учёт тренировок, календарь или фитнес-трекер в приложение не добавлены.
